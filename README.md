# Facebook Homepage Clone using Tailwind CSS

A responsive clone of the Facebook homepage built using **HTML** and **Tailwind CSS**. This project focuses on recreating Facebook's desktop interface while practicing modern frontend development techniques and utility-first CSS styling.

---

## Preview

This project replicates the visual layout of the Facebook homepage, including:

- Navigation Bar
- Left Sidebar
- Stories Section
- Create Post Card
- Feed Posts
- Right Sidebar
- Responsive Layout
- Facebook-inspired UI

## Development Workflow

To keep the project modular and maintainable, each major section of the Facebook homepage is developed in a separate Git branch.

### Branch Structure

| Branch | Component |
|---------|-----------|
| `main` | Stable version of the project |
| `navbar` | Facebook Navigation Bar |
| `left-sidebar` | Left Navigation Panel |
| `stories` | Stories Section |
| `create-post` | Create Post Card |
| `feed` | News Feed |
| `right-sidebar` | Sponsored & Contacts Section |
| `responsive` | Responsive Layout Improvements |
| `final` | Complete Facebook Homepage Clone |

Each component is implemented, tested, and committed independently before being merged into the `main` branch.
